# Respaldo del artefacto (beta)

`reto-microbiologia.html` es la versión completa del artefacto de Claude, en un solo archivo, tal como está publicada en claude.ai.

Tiene funciones que la web todavía no tiene:
- Flujograma evaluado (Virus y Hongos): el alumno sube la foto de su flujograma y Claude lo corrige según el nivel.
- Flujogramas resueltos (gráficos) en Estudio: 11 casos de Virus y 11 de Hongos.
- Modo flujogramas (4 niveles) y Modo mixto (6 preguntas + 2 flujogramas) en Virus y Hongos; las rondas normales son solo preguntas.
- Ahorcado dentro de cada estación (Hongos, Bacterias, Virus, Parásitos) y Ahorcado con fotos reales en Microscopio. Regla: una pregunta con imagen solo aparece si tiene su foto real (Laboratorio no tiene fotos todavía, así que su ahorcado no aparece).
- Visor de fotos con zoom (pellizcar, rueda, doble toque) en todas las imágenes.
- «¿Sabías que...?» espera a que el alumno toque o presione Enter.

Es solo un respaldo: no se publica en GitHub Pages. Para llevar esas funciones a la web hace falta un servidor que llame a Claude (ver README principal).
